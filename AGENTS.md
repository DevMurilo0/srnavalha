# Projeto: Barbearia Sr. Navalha

Sempre que a tarefa envolver desenvolvimento ou design frontend, utilize os plugins instalados relevantes:

- Taste Frontend: direção artística, composição editorial, identidade visual, layouts autorais e tipografia.
- Impeccable UI: UX, responsividade, acessibilidade, performance e refinamento visual.
- Emil Design Engineering: animações, transições, microinterações e componentes interativos.

Combine as diretrizes desses plugins quando isso melhorar o resultado. Use os arquivos e referências originais dos plugins disponíveis, não apenas seus nomes.

Preserve a identidade da Barbearia Sr. Navalha e procure qualidade visual comparável a referências selecionadas do Awwwards, sem copiar sites e sem introduzir componentes genéricos.

Preserve a arquitetura existente, priorize HTML, CSS e JavaScript compatíveis com Live Server quando apropriado e evite dependências desnecessárias.

Antes de finalizar alterações, verifique responsividade, acessibilidade, funcionamento das interações e respeito a prefers-reduced-motion.

Quando solicitar apenas planejamento ou prompts, não modifique o código.

Se algum plugin não estiver disponível, informe essa limitação e prossiga aplicando os princípios conhecidos, sem afirmar que utilizou o plugin.
