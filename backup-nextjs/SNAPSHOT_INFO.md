# Snapshot da implementação Next.js anterior

Cópia de segurança dos arquivos da implementação React/Next.js anterior, criada antes de converter a entrada principal para HTML estático. Inclui código-fonte, imagens, configuração, testes, documentação e as versões anteriores das páginas estáticas. Dependências instaladas, `.git`, `.next` e caches não fazem parte da cópia.

A implementação da raiz foi convertida para Live Server. Este diretório existe somente como cópia de segurança e não é necessário para executar a versão estática.
