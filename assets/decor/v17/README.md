# Gravuras V17

Oito vetores originais desenhados neste projeto, sem código ou desenhos de bibliotecas de componentes. `currentColor`, traços de 1,2 unidades, `vector-effect: non-scaling-stroke` na aplicação e `pathLength=1` nos traços animados. A marca da barbearia continua sendo a imagem oficial existente; estes ornamentos não a substituem.

Os SVGs são incorporados aos parciais canônicos em `templates/v17/`. Ao editar uma gravura, atualizar também o parcial que a utiliza e executar opcionalmente `node scripts/render-site.mjs`. O HTML entregue já está montado para Live Server.
