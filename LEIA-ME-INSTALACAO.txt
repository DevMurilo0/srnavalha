SR. NAVALHA V9

Abra index.html pelo Live Server no VS Code.
Alternativa: python3 -m http.server 8019 e http://localhost:8019
Não precisa de npm, React, Vite ou comando de build para visualizar.
Módulos JS precisam de servidor HTTP; não use duplo clique/file:// para avaliar animações.

Para regenerar o HTML após editar js/data/:
node scripts/build-v9.mjs

A agenda oficial é o AppBarber. Não há reserva fictícia ou estoque em tempo real.
Documentação: README.md e docs/TESTES_V9.md.
