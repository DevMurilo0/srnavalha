SR. NAVALHA — A ARTE DO RITUAL

1. Extraia o ZIP inteiro, preservando as pastas.
2. Abra a pasta sr-navalha no Visual Studio Code.
3. Clique com o botão direito em index.html e escolha Open with Live Server.

Não é necessário npm run dev, instalação de dependências ou build.
Não use file:// para testar módulos JavaScript.
Agendamentos acontecem no AppBarber oficial; o site não simula reservas.

Fonte canônica para futuras alterações: scripts/render-site.mjs e js/data/.
HTML pronto, CSS e JS também estão incluídos.
Leia README.md e docs/ritual/TESTES.md para detalhes e limites.
