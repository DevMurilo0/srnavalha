# Impeccable UI — Plugin do ChatGPT

Este é um pacote de **plugin**, criado a partir do ZIP fornecido pelo usuário. É um plugin **somente com instruções e recursos locais (sem conexão MCP)**.

- ID do plugin: `impeccable-ui`
- Skill interna: `impeccable`
- Manifesto: `plugin.json` (formato Agent Plugins 1.0)
- Recursos incluídos: `skills/impeccable/`

## Importação para o ChatGPT

Este ZIP é um pacote de plugin que pode ser usado em fluxos com suporte à importação. A instalação em ChatGPT depende de permissões da conta/workspace.

**Caminho oficial:** Plugins > Plugin Creator e descreva o plugin, anexando este ZIP, ou use a opção de Upload de plugin, se disponível para seu workspace. Não é suficiente enviar o ZIP numa conversa qualquer para deixá-lo instalado.

Os scripts originais foram preservados. Alguns exigem Node, Chromium, CLI ou acesso ao sistema e não poderão rodar em todos os ambientes do ChatGPT. O plugin não cria, por si só, acesso ao computador, ao navegador ou ao código-fonte do usuário.

Não houve publicação no Diretório de Plugins nem teste de instalação dentro de uma conta ChatGPT.
